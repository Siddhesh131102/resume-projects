#  Walmart Sales Data Analysis (Pandas)

##  Overview

In this project, I explored Walmart sales data using Python (Pandas) to understand how sales change over time, how different stores perform, and what factors might influence sales.

---

##  What I wanted to find

* Which stores perform the best
* How sales change month-to-month and year-to-year
* Whether holidays increase sales
* Which months contributed most to growth
* If factors like CPI, fuel price, or unemployment affect sales

---

##  Tools I used

* Python
* Pandas
* Google Colab

---

##  What I found

* Some stores consistently perform better than others
* Sales are generally higher during holiday periods
* March, June, and August showed the highest growth (YoY)
* External factors like CPI, fuel price, and unemployment have very little impact on sales

---

##  Files in this project

* `Walmart_Sales.csv` (dataset)
* `Walmart_Sales_Analysis.ipynb` (analysis code)

---

##  How to run this

1. Open the notebook in Google Colab or Jupyter
2. Upload or place `Walmart_Sales.csv` in the same folder
3. Run all cells
